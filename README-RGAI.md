# RGAI 5.26.9.5（游戏娱乐版）

> RG启航编程工作室出品 · Poland ball Studio 荣誉认证 🐝

一个用 C++ 写的命令行聊天机器人，会思考、会聊天、会玩猜数字，还会把自己"安装"到你的电脑上。

## ✨ 功能列表

| 功能 | 说明 |
|------|------|
| 💬 日常聊天 | 关键词回复，带 `ThinkingAndSay()` 思考动画 |
| 🎮 猜数字游戏 | 对它说"无聊"就开局，`rand()` 随机 1~100 |
| 🪟 弹窗问候 | `MessageBox` 弹窗版打招呼 |
| 📦 本地安装 | 输入指令用 `CopyFileW` 把自己复制到安装目录 |

## 🚀 运行方法

1. 用 Visual Studio 或 小熊猫C++（Red Panda Dev-C++）打开源码
2. 编译运行
3. 跟它聊天，说"无聊"开启猜数字

## 📜 版本历史

- **5.26.9.5（游戏娱乐版）**：移植猜数字小游戏，重构出 `game()` 函数
- **5.26.8.23**：初版功能整合

## 🧠 技术要点

- `string` 索引与字符数组
- `srand(time(0))` 随机数播种
- `while` 循环 + `if-else` 分支链
- 函数拆分：`game()`、`ThinkingAndSay()`
- Windows API：`MessageBox`、`CopyFileW`
